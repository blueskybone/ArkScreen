# ArkScreen - 公招助手

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 快速公招 | 在游戏内截图识别公招标签，也可以手动选择标签计算结果 |
| 实时数据 | 查看理智、无人机、公招、会客室和训练室等状态 |
| 桌面组件 | 提供 1×1、1×2、2×2 和 2×3 组件，支持多种布局与视觉主题 |
| 自动签到 | 支持明日方舟与终末地森空岛签到，也可以手动一键签到 |
| 干员资产 | 查看持有、练度、潜能、模组和未获取干员，并生成分享图片 |
| 寻访统计 | 支持官服与 B 服记录同步、统计报告、原始记录和本地导入导出 |

## 快速开始

1. 从 [GitHub Releases](https://github.com/blueskybone/ArkScreen/releases) 下载并安装最新版本。
2. 在首页账号管理中添加森空岛账号，用于实时数据、干员资产和签到。
3. 如果需要寻访统计，请在寻访页面单独添加寻访记录账号。
4. 进入“功能”页面，根据需要开启快速公招、自动签到和桌面组件，并授予对应权限。

## 账号说明

应用内存在两套相互独立的账号：

| 账号 | 用途 | 凭证关系 |
| --- | --- | --- |
| 森空岛账号 | 明日方舟实时数据、干员资产、明日方舟／终末地签到 | 独立 |
| 寻访记录账号 | 同步与统计明日方舟寻访记录 | 独立 |

账号凭证保存在应用本地。请不要向他人分享应用数据、备份文件或包含敏感信息的调试内容。

## 权限说明

| 权限或设置 | 用途 |
| --- | --- |
| 悬浮窗与截屏 | 在游戏内截图识别公招标签并展示结果 |
| 通知 | 展示签到、截图识别、组件刷新和应用下载等后台任务状态 |
| 后台运行、自启动与电池优化 | 提高自动签到和桌面组件定时刷新的可靠性 |
| 安装未知应用 | 仅在使用应用内更新并安装 APK 时需要 |

不同 Android 系统对后台任务限制不同。如果自动签到或组件刷新不稳定，请检查应用内对应功能的运行状态与权限提示。

## 运行环境

| 项目 | 要求 |
| --- | --- |
| Android 版本 | Android 8.0（API 26）及以上 |
| 网络 | 实时数据、签到和寻访同步等功能需要网络连接 |
| 快速公招 | 系统需支持截屏授权与悬浮窗 |

## 开发构建

项目使用 Kotlin、Android Views、Room、Retrofit、WorkManager 和少量 JNI/C++ 代码。

准备 JDK 17 与 Android SDK 后，可以通过 Gradle Wrapper 构建：

```powershell
.\gradlew.bat :app:assembleDebug
```
