## ArkScreen - 公招助手

主要功能：游戏内截图识别公招，森空岛自动签到，桌面组件理智监控。

功能详细介绍：https://ngabbs.com/read.php?tid=37670963

快速公招使用方法及软件界面预览：https://www.bilibili.com/video/BV1624y1q7Cv

交流群：924153470
